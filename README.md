## 🚀 Semester 2 – Entrepreneurial WIL Project

### GugsLocalConnect

GugsLocalConnect is a community-based digital platform designed to connect residents of Gugulethu with local businesses and service providers. The project aims to improve the visibility of local businesses, make services easier to discover, and support the local community. During this project, our team used Agile principles to organise work, define user requirements, plan sprints, allocate responsibilities, and track development progress using Trello. My role was **Product Owner**. My responsibility was to help ensure that the final system addressed users' needs and stakeholder expectations.
